# Предложения и рекомендации

Этот раздел — единственное место во всей документации, написанное по-русски (по просьбе владельца проекта). Здесь
собраны мои замечания, дополнения и предложения по итогам ревью кода. Это не техническая документация "как есть"
(она — в остальных файлах `docs/`, на английском), а рекомендации "что можно сделать дальше".

Я не вносил изменений в модели, не запускал миграции и не менял поведение приложения — только изучил код,
запустил проект в Docker для проверки и написал документацию. Всё ниже — предложения на ваше усмотрение.

- [`multi-user-migration.md`](multi-user-migration.md) — что именно нужно проверить/переделать при переходе на
  многопользовательский режим.
- [`security-and-sharing.md`](security-and-sharing.md) — приоритетные меры по безопасности, в первую очередь
  вокруг `apps.sharing` и загрузки файлов.
- [`feature-gaps.md`](feature-gaps.md) — функциональные пробелы относительно заявленной цели проекта (в первую
  очередь — уведомления об истечении гарантии/срока договора).
- [`code-quality-and-docs.md`](code-quality-and-docs.md) — актуализация `CLAUDE.md`, локализация, тесты, мелкий
  технический долг.
