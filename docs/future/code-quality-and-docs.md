# Документация, локализация, мелкий технический долг

## `CLAUDE.md` сильно устарел

Корневой `CLAUDE.md` описывает общий шаблон "GeoDjango geo-tracking", упоминает только `apps.users` (причём как
"пустую заготовку", что уже не так) и вообще не знает о существовании `apps.content`, `apps.documents`,
`apps.attachments`, `apps.comments`, `apps.sharing`, `apps.links`, `apps.notifications` — то есть практически всей
реальной функциональности проекта. Поскольку `CLAUDE.md` — это первое, что читает любой AI-агент перед началом
работы, его актуальность напрямую влияет на качество будущей AI-assisted разработки. Я не стал переписывать его
сам (это не было прямо запрошено, и правки `CLAUDE.md` — не то же самое, что подготовка документации в `docs/`),
но рекомендую в какой-то момент:
- заменить общее описание на короткую версию из `docs/README.md` ("что это на самом деле");
- либо оставить `CLAUDE.md` компактным и добавить в него одну строку-указатель на `docs/README.md` как источник
  истины по архитектуре — это дешевле поддерживать в актуальном состоянии, чем дублировать.

## Локализация — очень неровное покрытие

Правило из `CLAUDE.md` ("gettext_lazy в моделях, gettext во view, blocktranslate в шаблонах") соблюдается
примерно в половине кода: `apps.documents` и `apps.comments` — соблюдают полностью; `apps.content` (включая
`base.html` — то есть буквально каждую страницу сайта) и `apps.sharing` — почти нет. Если проект когда-нибудь
предполагает интерфейс не только на русском — это стоит привести к одному стандарту сейчас, пока кодовой базы не
стало ещё больше. Полный список конкретных файлов — `docs/known-issues.md`, KI-5.

## Тестовое покрытие

Тесты в целом неплохие (106 из 107 проходят), но есть явные пробелы:
- `apps.users` — вообще нет тестов (JWT-эндпоинты, сигнал обновления last_login);
- `apps.documents` — нет отдельного тестового файла, покрытие только косвенное через `apps.content`;
- `apps.sharing` — протестирована только модель/`can_view()`, нет теста самого получения ссылки (потому что и
  самой вьюхи пока нет).

## Мелочи, не требующие срочного внимания

- Два предупреждения `RemovedInTreebeard8Warning` (устаревшие вызовы `Note.get_ancestors()`/`get_children()`) —
  дешёво поправить сейчас, пока их всего два места.
- N+1 запросы в `DocumentTable` (счётчик вложений) и на главной странице заметок (обложки) — не критично при
  текущем объёме данных одного пользователя, но стоит поправить заодно с любыми будущими правками этих мест.
- В `.env.example` есть заготовленные, но нигде не используемые настройки: `REDIS_CACHE_URL` (нет `CACHES` в
  settings) и заголовки Cloudflare (нет middleware, которое бы их читало). Либо довести до использования, либо
  убрать, чтобы не вводить в заблуждение.
- `/health/` возвращает 500 из-за непроверяемого email-бэкенда — если этот адрес когда-нибудь станет
  liveness-проверкой в оркестраторе/балансировщике, это надо будет поправить заранее (детали —
  `docs/known-issues.md`, KI-3).
